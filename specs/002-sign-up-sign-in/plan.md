# Implementation Plan: Sign-Up / Sign-In with Notes Redirect

**Branch**: `002-sign-up-sign-in` | **Date**: 2026-06-11 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/002-sign-up-sign-in/spec.md`

## Summary

Build a React 19 SPA with sign-up and sign-in forms that validate email/password, call a
mock REST API (MSW), and redirect authenticated users to a placeholder Notes page. The
feature also initialises the full project structure: Vite + TypeScript + Tailwind + React
Router, MSW for mocking, Vitest + RTL + Playwright for testing, Docker for containerisation,
and GitHub Actions for CI/CD.

## Technical Context

**Language/Version**: TypeScript 5.x, strict mode; Node 20 LTS (pinned in `.nvmrc`)

**Primary Dependencies**:
- `react@19`, `react-dom@19`, `@vitejs/plugin-react`, `vite@5`
- `react-router-dom@6`
- `tailwindcss@3`, `postcss`, `autoprefixer`, `clsx`
- `msw@2` (mock service worker)

**Dev / Test Dependencies**:
- `vitest`, `@vitest/coverage-v8`
- `@testing-library/react`, `@testing-library/user-event`, `@testing-library/jest-dom`
- `jsdom` (Vitest browser environment)
- `@playwright/test`
- `eslint`, `@typescript-eslint/eslint-plugin`, `eslint-plugin-react-hooks`, `prettier`

**Storage**: None (no persistence; mock in-memory store in MSW handler only)

**Testing**: Vitest + React Testing Library (unit/component); Playwright (E2E P1 flows)

**Target Platform**: Browser SPA; served from Nginx in Docker; deployed to AWS ECS via ECR

**Project Type**: Single-page web application

**Performance Goals**: Page load < 2 s; form submission feedback < 500 ms

**Constraints**: MSW MUST NOT be active in production build; Docker image serves static
assets from Nginx; no real backend required to run or test

**Scale/Scope**: 3 routes (`/`, `/signin`, `/notes`); 3 pages; 1 mock API endpoint pair
